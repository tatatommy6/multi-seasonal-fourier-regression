# NOAA 조위 데이터 MSFR 베이스라인 비교

## 실험 조건

- 관측소: NOAA The Battery (`8518750`)
- 데이터: 2010년 1월 1일부터 2021년 12월 31일까지의 검증된 시간별 조위
- 테스트 구간: 전체 관측값의 마지막 10%이며 2020년 10월 19일부터 시작
- 예측 시작 시점: 24시간 간격
- 예측 구간: 24시간, 168시간, 720시간
- 모든 베이스라인은 각 예측 시작 시점 이후의 실제 관측값을 사용할 수 없음
- 주기 학습 MSFR와 주기 고정 MSFR는 모두 seed 42와 동일한 설정을 사용

이 비교를 진행하기 전에 MSFR의 주기 초기화 문제를 수정했다. 기존에는 inverse
softplus로 초기화한 뒤 공개되는 `cycle` 값에 `0.001`시간이 추가되어, 사용자가 지정한 고정 주기가 정확하게 표현되지 않았다. 이처럼 작은 주기 오차도 긴 학습 구간에서는 큰 위상 오차로 누적될 수 있다.

## 베이스라인과 MSFR의 차이

평균 베이스라인은 모든 미래 시점에 과거 조위의 평균값을 사용하고, 마지막 관측값 베이스라인은 예측 직전의 조위를 미래 전체에 그대로 사용한다.
두 방식 모두 **밀물과 썰물의 반복적인 움직임**을 표현하지 못한다.

12시간, 24시간 naive 베이스라인은 직전 12시간 또는 24시간의 관측 패턴을 반복한다. 짧은 예측에서는 최근 조위 패턴을 활용할 수 있어 비교적 강하지만, 실제 주요 조위 주기인 약 12.42시간과 반복 길이가 다르다. 따라서 예측 기간이 길어질수록 위상이 어긋나는 문제가 발생한다.

MSFR는 M2, S2, K1, O1, 연간 주기를 Fourier 특성으로 동시에 표현한다. 주기 고정 MSFR는 이 주기들을 그대로 사용하고, 주기 학습 MSFR는 데이터에 맞게 주기를 조금씩 조정한다.
과거의 짧은 구간을 반복하는 방식이 아니므로 장기예측에서도 위상을 안정적으로 유지할 수 있다.

## 최고 베이스라인 대비 성능 차이

각 예측 구간에서 MAE와 RMSE가 가장 낮은 일반 베이스라인을 기준으로 비교했다.

| 예측 구간 | 비교 기준 | 베이스라인 MAE | MSFR MAE | MAE 개선율 | 베이스라인 RMSE | MSFR RMSE | RMSE 개선율 |
| ---: | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 24시간 | 12/24시간 naive 평균 | 0.207194 | 0.168962 | **18.5%** | 0.259480 | 0.220254 | **15.1%** |
| 168시간 | 평균 | 0.457961 | 0.168406 | **63.2%** | 0.533718 | 0.219801 | **58.8%** |
| 720시간 | 평균 | 0.459653 | 0.167354 | **63.6%** | 0.535643 | 0.218940 | **59.1%** |

24시간 예측에서는 naive 베이스라인도 최근 패턴을 활용해 비교적 좋은 성능을 보이지만, 주기 학습 MSFR가 MAE를 18.5%, RMSE를 15.1% 더 낮췄다. 168시간과 720시간에서는 naive 방식의 위상 오차가 누적되어 단순 평균보다도 성능이 나빠졌다.
반면 MSFR의 오차는 예측 구간이 길어져도 거의 증가하지 않았다.

주기 학습 MSFR는 주기 고정 MSFR보다 모든 예측 구간에서 MAE와 RMSE를 약 0.7~0.9% 추가로 개선했다.
따라서 베이스라인과의 큰 성능 차이는 여러 주기를 동시에 표현하는 Fourier 구조에서 나오며, 주기 학습은 작은 추가 개선을 제공한다.

## 결론

MSFR는 안정적인 여러 주기가 미래 값을 결정하는 조위 데이터에서 일반   baseline 보다 높은 성능을 보였다.
특히 24시간 예측뿐만 아니라 168시간과 720시간 장기예측에서도
오차가 거의 증가하지 않았으며,
최고 베이스라인보다 **MAE를 최대 63.6%, RMSE를 최대 59.1% 낮췄다**.

이 결과는 MSFR가 최근 관측값을 반복하는 방식보다 여러 주기와 위상을 직접 학습하는 방식에 적합하다는 것을 보여준다.
전력 데이터처럼 최근 상태와 외부 요인의 영향이 큰 데이터에서는 장점이 제한적이었지만, 조위처럼 시간에 따른 반복 구조가 강한 데이터에서는
MSFR의 다중 Fourier 구조가 효과적으로 작동했다.

다만 학습 가능한 주기 자체가 제공한 추가 개선은 약 1% 이내였다. 따라서 현재 성능의 대부분은 다중 Fourier 표현에서 나오며,
주기 학습 기능의 효과를 더 확실히 검증하려면 초기 주기를 정확히 알 수 없는 데이터나 다른 NOAA 조위 관측소에서도 같은 실험을 반복할 필요가 있다.

## 실행 방법

```shell
python -m benchmark.NOAA_tide_hourly_height.train_msfr \
  --seed 42 \
  --save-ckpt model/noaa_tide_msfr_learned_seed42.ckpt \
  --output-dir benchmark/NOAA_tide_hourly_height/plots_learned_seed42

python -m benchmark.NOAA_tide_hourly_height.train_msfr \
  --seed 42 \
  --freeze-cycles \
  --save-ckpt model/noaa_tide_msfr_fixed_seed42.ckpt \
  --output-dir benchmark/NOAA_tide_hourly_height/plots_fixed_seed42

python -m benchmark.NOAA_tide_hourly_height.compare_msfr
```
